# Luxshmi Driving School

Next.js website for Luxmy Driving School — automatic driving lessons, overseas licence conversion, and test preparation in Western Sydney.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Compatible with [Vercel](https://vercel.com) and other Next.js hosts. Add images to `public/` (`luxmy-logo-transparent.png`, `luxmy-brand-card.jpg`) before production deploy.
